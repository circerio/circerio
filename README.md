## OPEN CASE FILES

### 01 / THE WORLD THAT LEFT ITS CONSOLE

**[XC2-Recomp](https://github.com/circerio/XC2-Recomp)** — Native Windows static-recompilation work for *Xenoblade Chronicles 2*. Because apparently “it only runs there” is an invitation to investigate.

`Public record: documentation and roadmap only; no builds or game files.`

### 02 / THE FRAMES THAT WERE NEVER THERE

**[OptiScaler engineering fork](https://github.com/circerio/OptiScaler)** · **[RenoDX provider fork](https://github.com/circerio/renodx)** — Experimental DX11 frame-generation / MFG engineering for *Trails in the Sky 1st Chapter*. Rendering pipelines have opinions. I have questions.

`Public record: game-specific, source-only work in progress; not an official release.`

### 03 / STEREO WITH AN IDENTITY CRISIS

**[StemSpace source preview](https://github.com/circerio/StemSpace-source-preview)** — Exploring AI-assisted stereo-to-7.1 DSP while trying not to destroy the original stereo image in the process.

`Public record: experimental source preview, not an installable AI upmixer.`

### 04 / THE TABLET THAT REFUSED A KEYBOARD

**[Kira Tablet](https://github.com/circerio/kira-tablet)** — A touch-first Windows tablet fork, because a touchscreen should not have to pretend it is a laptop.

`Public record: Windows preview.`

### 05 / THE PIXELS THAT LIED

**[OBS Canvas Rescaler](https://github.com/circerio/obs-canvas-rescaler)** — A local browser tool for the uncomfortable possibility that fewer effective pixels can produce a better-looking result.

`Public record: usable local tool and reproducible comparisons.`
